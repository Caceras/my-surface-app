## Deliberate boundaries

Hotword/background inference, autonomous model commands, cloud/MCP, images, notifications/bubbles, Wear OS and Android Auto require separate product and platform contracts. They are not defects in the current foreground text/voice assistant. The broader [Android capability plan](../android-native-plan.md) tracks these possibilities.

## Repair acceptance

`DeepAuditTest` covers A01–A08/A11: blank selection Send, private editor, retained cursor, paused Voice recreation, failed/echoed question recovery, safe retry choice, archive ID validation/merge and calendar limits/motion. `ShotTest` adds selection, failed-voice and narrow large-answer fixtures for A01/A04/A10 and revisits light/dark Settings for A09/A13. The language warning removal intentionally replaces the old heuristic tests with a real multilingual chat regression; it is a changed product contract, not a weakened failure gate.

A12 adds `reports/lint-inventory.json` to verified evidence. Counts remain separated by flavor; the same warning can appear twice across builds. Verification recomputes the inventory from original XML. Docs checks now include nested audit pages and AGENTS.md. Final Android results, screenshot acceptance, exact source/run, publication and APK hashes belong to the build-specific evidence and PR record; an implementation row alone does not certify them.

Baseline lint triage: core 67 / Nano 85 warnings. Categories: localization-style SetTextI18n (37 each); verified dead-resource candidates (14 core/11 Nano); native framework versus transitive AndroidX recommendations (Nano UseKtx 14, compatible drawable 6 and switch 1); version/target/dependency recommendations; three touch-listener accessibility notices per flavor; view-constructor and guarded API notices. No blanket suppression or blind SDK upgrade was applied. D07 tracks the remaining work.
