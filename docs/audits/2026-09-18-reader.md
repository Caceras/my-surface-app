# Reader and streaming audit

Scope: user-reported robotic reading, lagging streaming, raw Markdown and excessive UI copy. Baseline: f815ff4ce68501d378564f1af09e5ecc55961534; prior workspace merged as fc7e90cc1ce55b5c6413e725840a948cf1e8fbf8 after merge validation run 35363586023 passed.

| Finding | Change | Acceptance |
|---|---|---|
| Saved reader selects by locale but ignores quality; chat has a separate policy | Shared installed/offline quality-first voice selection and explicit preference/sample picker | Policy and reader regressions; listening quality still requires Pixel |
| Every reader sentence flushes the TTS queue | Queue upcoming sentences, fence callbacks by playback generation | Queue mode, exact spoken content, existing pause-before-init and interruption coverage |
| Failed initialization can later show silent playback as running | Explicit initialized/ready distinction | Failed initialization followed by Play stays stopped with text intact |
| Every reader publication rewrites the whole note | Persist text only when changed; positions and speed separately | Existing recovery tests; storage format unchanged |
| Markdown implements only bold/headings/bullets | Shared pure parser plus native italic/combined/code/link spans; preserve escaped and literal syntax | Parser examples, rendered spans, plain speech and partial-token tests |
| Fixed 48 ms redraws replace full TextView buffers | Display-frame coalescing and in-place changed-paragraph edits | Burst/cancel timing, buffer identity, corrected text and bounded span-count regressions |
| Welcome slogan/cards and decorative settings copy compete with actions | Plain question title, single writing shortcut, descriptive settings labels and plainer response instructions | Native chat/compact reader/light/dark renders; no wording-only regression added |

The normal Android gate must pass before publishing this candidate. Current evidence is source review and local pure-parser checks until CI results are attached to the PR. Fresh affected native renders must be inspected from that run. No physical Pixel, Nano speech, network-provider, accessibility, battery or frame timing claim follows from JVM captures. No signing key has been invented, recovered or placed in public storage; export before a signature-conflict uninstall.
