# Everyday polish audit — 2026-09-18

## Scope

Visual and interaction refinement only. Preserve Today · AI · Library, local storage, voice/reader behavior, model providers, permissions and backup compatibility.

## Findings

Build 141 was functionally sound but visually over-inflated: most actions used large fully rounded pills, the Today screen repeated slogan-like section copy, the empty chat duplicated the composer with a second writing call-to-action, and settings mixed voice controls into the AI section. The note editor and Library also felt dense because cards, fields and chips all competed at nearly the same visual weight.

## Changes

- Shared controls keep accessible 48 dp targets but use tighter typography, padding and 18 dp radii.
- Chat header, transcript, empty state, composer and utility row use less vertical space; the redundant empty-state writing button is removed.
- Today uses literal section names: Tasks, Calendar, Pinned and Routines. Filler subtitles are removed.
- Workspace cards, search fields, title hierarchy and capture bar are tightened without changing record behavior.
- Settings adds a Voice section and renames Android access/Conversations to Android/Data for faster scanning.

## Acceptance

Run preflight, the full Android gate, inspect fresh chat/Today/Library/note/settings/voice/reader screenshots in light and dark/large-font fixtures, verify both APK signatures and publish only the build-specific Nano asset. Physical-device feel, installed voice quality and frame timing remain device acceptance items.
